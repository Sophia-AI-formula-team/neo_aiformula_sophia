# Topo / MapAssist 简易红绿灯调整

问题：车辆没有灯的米制距离，旧原子输入又依赖 `enable_signal_approach` 才订阅；旧红灯等待分支可能自动进入拓扑绕行。用户要求保留 topo 建图，只使用稳定红灯等待、稳定绿灯恢复。

本次原生 MapAssist 默认采用 `traffic_policy=stop_wait`，关闭按距接近。原子颜色输入保留时间戳年龄和序号检查，距离为空也可使用。稳定红灯输出零 Twist 并保持等待；未知、断流、重复和过期消息不能释放等待。稳定有效绿灯后，仍需恢复延时、新完整车道点和新控制指令。红灯等待优先于 OA 转发，不自动左转或绕行。

Topo 轨迹记录、闭环、地图对齐和有限方向修正不变。旧分支仅以显式 `traffic_policy=legacy` 保留，方便复核历史测试；`63eec2d` 仿真结果不能用作此次改动验收。现有 primitive/costmap 规划链不在修改范围。

车辆保持 shadow 输出；源码更新不等于已安装或已运行。当前 Sigmoid 电机版本的零指令轮速异常尚未修复，零 Twist 不能据此视为实车停车验收。
