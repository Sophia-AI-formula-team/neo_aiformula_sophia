## 信号灯决策

正常跟线时，车道上没有灯框是常见情况。确认红灯后，首圈按停车位置旗标停车；地图已匹配时，只有当前位姿存在可行绕行且达到切入条件，才提交转弯。

红灯接近或等待期间，丢失灯框（`unknown`）、收到无法判为红绿的颜色，或者红灯观测失去时效，均停车，即使停车点旗标仍为 False。后续圈若只是丢失了灯色，重新确认红灯且当前有可行切入轨迹时可绕行。已因停车点、距离信号缺失或无可用绕行而锁定停车时，等待确认绿灯。绿灯放行需要一条新到达的绿色消息，使 0.5 秒窗口内至少 3 条观测中的绿色占严格多数。已提交的绕行按轨迹完成。

自动速度链中，红灯停车优先于 OA。停车时 MapAssist 向电机速度话题立即发零，再以默认 20 Hz 持续发零。OA 标志、地图或 LYA 数据暂时缺失时，停车定时器仍可工作。绿灯确认后，OA 仍接管则等待选择器的新三点就绪信号和新 LYA 速度，否则等待新视觉三点和新 LYA 速度。

11 月 19 日两种识别器共用 `/aiformula_perception/yolop_a3/traffic_light/state`。这个 String 只提供颜色和接收时刻；同一帧的框、相机源时间和红像素数在相邻的 `detections` JSON 中。回放时应保留两者，分别核对灯色投票与停车位置旗标。
