# OA 1B 0.1.2 验证记录

## 旧版和新版在同一套上、下游切换

使用隔离的 amd64 ROS 2 Foxy 容器，回放相机原图和静态里程计，分别启动原 A3 V14、A4 和 A4L。原 LLP、车道选点、电机 console、LYA、MapAssist 和 OA 2.1 使用车端归档代码。安装两次只构建 `oa_1b`，旧 `mapassist` 命令的 SHA-256 一致。安装台架没有单独配置 A3 venv 给 OA 1B。

- 每个选项都只看到一个原 YOLOP 节点发布公共识别。运行中的 OA 1B 进程没有载入 Torch、CUDA 或 CUDA runtime 动态库。新版 MapAssist 订阅私有灯态和停车标志。A3 V14 的四个同一源时间戳样本中，原 JSON 都是 50 个红像素，OA 1B 去重后都是 25 个。A4 和 A4L 在同一张台架原图上均报告 25 个像素，去重后也是 25。
- 第三步运行新版时，开旧版会被同一把启动锁拒绝。对新版发 Ctrl+C，第三步节点退出，原 YOLOP、原 LYA 仍在用同一 ROS 域。随后同一套上、下游成功接回旧 `mapassist`，同时启动新版同样被拒绝。
- 再次启动 `mapassist_b inner 50` 后发 SIGHUP，第三步节点全部退出，原 YOLOP 和 LYA 仍在运行。之后分别结束各终端，DDS 节点为零。
- 台架的四个对齐样本中，原 LYA、MapAssist 最终指令、电机仲裁选中的速度一致，DDS CAN 帧也和电机记录逐字节一致。原 C++ LLP 在最后单独停止 Allnodes 侧时返回 245，相同旧 LLP 曾在隔离测试中单独复现 SIGINT 析构段错误，第三步停止与重启均成功。

## 同灯复核回放与耗时

将三场外圈原图及对应的 A3 V14 YOLOP JSON 按源时间戳重放。420 个检测帧中 3 帧已过期。再次亮红的 50 帧由 41 帧判红提高到 47 帧。82 个熄灯帧未新增红判。原来有 20 帧达到 50 像素，去重后低于 50。合成单测还覆盖了一块大小相同、位置偏离灯区的红色区域，重复两帧也保持 `unknown`。

0.1.2 移除了 0.1.1 的额外推理实例、模型权重和 GPU 预热。用禁用 GPU 的容器重放时，CPU 像素处理的中位数约 0.09 ms。此数值只覆盖去重、灯区检查和状态更新，从已解码图像开始计时。A4/A4L 的验证覆盖台架接线、启动和结束。上述再次亮红的数据来自原 A3 V14，三个型号的车端停车距离和带轮运动仍有待现场验证。[逐场回放数据](evidence/replay.json)
