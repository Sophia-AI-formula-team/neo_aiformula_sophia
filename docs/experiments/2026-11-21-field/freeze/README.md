# 2026-11-21 OA 2.3 车端冻结

时间均为 JST。候选基于 Neo 9062d326c221f088748cb958d6c0421d1330f1b0。本目录收录 Jetson 回读版本、选点和手柄测试与运行依赖。OA 与 MapAssist 的正式代码在同一提交的 workspace/src/aiformula/。

| 项目 | 冻结行为 |
| --- | --- |
| OA 发布坐标 | A.y 乘 0.5。A、B、C 的 x 使用路径原值。B.y 和 C.y 使用原值。独立点和整组 ABC 共用这一输出。 |
| 正常清障 | 连续 3 帧确认清障后归还普通车道，清空 OA 的路径、旧窗口和投票。里程计重建且当前有效掩码为空时，可交还旧路径的选点权。 |
| 异常 | OA 工作中传感器缺失、过期或持续约 1 秒没有可用点窗时清空绕行并发布 /point_flag=false。进程失联时，选择器在约 0.6 秒后解除 OA。MapAssist 在故障或 OA 心跳缺失期间挡住自动速度。OA 以 3 张新鲜空掩码恢复健康，恢复自动需要新的完整车道 ABC。 |
| 手柄 | 接管重置 OA 和候选点，松手后等待新视觉帧。测试使用带时间戳的合成手柄状态和实装 ROS 节点。 |
| 终端与桌面入口 | allnodes → yolop 选 A3/A4/A4 Lite 一档 → mapassist → lya 或 lya_2 二选一。MapAssist 默认外圈、50 红像素，负责启用 OA 与手柄交接。旧 Allnodes 必须退出，当前快捷方式才会启用带时间戳的 motor 状态。 |
| LanePoints | 已装车的 3 点门槛和同帧条件源码 SHA-256 为 016d7ae2da8f6e89128ce53337f4b4d48cdf1ecaaeaf0fd9c97900a389270c57。 |
| A3 V14 | 几何红面饱和度 45，红框置信度 0.30，MapAssist 默认停车位置门槛 50 像素。CPU 回放 P3 为 red、152 像素。 |
| LYA | 原版实装 SHA-256 b4f133d7f57e2b292b005a86133961db373948017c0440895bd9b336d4e42576。LYA 2 见本目录源码，两者入口互斥。 |
