# Unity 局部动作学习与风险对照

## Objective and scope

在已有标定的 Unity 中从驾驶结果学习快行、收油和横移。保存训练、盲测、完整跑圈和失败影片，按用户要求将本轮视频上传到私人 Google Drive。实验仅在模拟器运行。

## Work performed

第一版用 12 组相同感知输入共 72 次物理运行拟合回报，按布局留一验证后冻结。独立测试执行八对短段和一对整圈。第二版改变训练方法，用 48 次新增练习和原训练集学习额外风险以及收回动作的代价，按 12 个父布局分组验证。冻结之后执行四对新场景，最后复跑三个已公开场景。两版合计 154 次 Unity 运行。行驶实录和训练矩阵分别渲染，合辑逐帧与原分片对照。影片只使用仿真场地和车载 UI。核对了静态/运动属性、云端目录、上传完成提示和云端预览。H06 经核对为一个慢速横移桶，合辑及单片按真实场地更正。

## Evidence and result

第一版八场中安全完段由 5/8 到 6/8，增加一处弯中碰撞；双方安全的三个障碍段用时变化中位数为 −24.7%。H05 加速并换线，以约 1.01 秒清空余量先于横移桶驶过。第二版四对全新压力测试均为 4/4 合格，八次均回退，物理轨迹与基线逐行相同。已知整圈复验恢复 88.02 秒完圈。已知 H07 改用慢速内线，净距 2.274 米；在风险扣分前它已经选中该动作。[数值摘要](evidence/summary.json) 与 [录像校验清单](evidence/videos.json) 保存于本回执。完整试次和复现命令在 codexws/learned_racing/unity_laps。

## Risks and blockers

两版都未满足预登记的全面改进要求。第二版在新样本上过于保守。局部动作类型、控制结构和安全评价仍由人设定。跟踪用仿真车身姿态补偿自车运动；换电以后车辆响应的辨识及真实轮速接口尚待独立验证。全圈第二次复跑为已知布局诊断。

## Next agent actions

训练与压力测试继续按父布局分开。针对能达成同等余量的场景，单独评价连续速度和横移调整，并把误识别或跟踪重建作为输入质量记录。现有两个新策略均作为可选实验保留，进入实车实验须单独授权并验证运动输入。
