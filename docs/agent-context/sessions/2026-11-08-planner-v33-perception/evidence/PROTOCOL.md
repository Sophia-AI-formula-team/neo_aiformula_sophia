# V3.3：先恢复可信 baseline，再训练

输入基线：5e8c8e73a1e8b5f9cc5cb652834e8efeb4dcd76f。旧 V3.0 / V3.2 验收不覆盖、不重写。

## 不变条件

- 控制输入仅当前 RGB、安装的 A4 lane/object 输出、轮速代理、raw gyro、固定相机/车身标定；没有世界位姿、GNSS、赛道中心线、预载整图或障碍真值。每次出生清空记忆。
- 裁判、录像可读真值；与策略进程严格隔离。仿真仍为原安装物理与三轮模型，判负仍为全部轮心出界或车身碰桶。另报车身越界，不把比赛近似当四轮真实轮胎验收。
- 每次修改给独立版本、配置和源哈希；每次失败保留。开发用旧场景，最终留出场景在冻结方案后才运行。看过的留出失败转为开发证据，下一轮重新留出。

## 训练准入（全部满足才开始长训练）

1. 感知回放：同一 RGB / A4 / wheel / gyro 序列，原始、空间处理、因果时序三版对比。1–3 m 真实可见路界在运动补偿后的边界残差 p95 ≤0.15 m，且比原版下降至少50%；只在两帧确实观测到同一边界时统计。必须同时报告覆盖率、缺失率、道路误扩张，不能通过删除困难帧或降低覆盖率通过。视场边缘不得作为道路方向；不存在或过期的观测保持 unknown。
2. 闭环基础：8个新的随机起点完成8/8完整圈，零碰撞、零全轮出界；另作4个含短时lane-mask缺失/抖动的完整圈，至少4/4。最慢一圈必须在260秒内，零停车作弊；平均速度≥2.0 m/s。直道转向反复次数与总变差不高于旧版的50%，同时报告实际横向运动，不能仅滤指令。
3. 障碍准入：A可钻、B不可钻需绕、C两路可选、静止、移动、混合、连续、弯中各2个新布局，共16段，零碰撞/出界，16/16完整通过。合理减速算正确；所有可行方案比较完整通过时间，不把提前失败算快。
4. 执行预测：固定短命令片段核对轮速/gyro响应，报告预测与真实执行差异；需要改外部控制限幅时，依据安装的自主控制接口单独版本记录，不改物理或裁判来通过。

## 训练与最终速度验收

准入前仅小规模诊断与方案试验，禁止直接重复30,000次旧 surrogate。通过后先比较新 baseline 与沿用 V3.2 参数；仅在新观测和执行模型下仍有效的系数作为初始化。训练至少10,000个程序生成的独立试错，记录实际episode数；GPU并行候选搜索不冒充多GPU或真实Unity跑圈。

训练后冻结：新8起点与16障碍布局重新验收，仍须零失败；以成对完整圈时间与障碍区完整通过时间为速度目标，整圈中位用时改善≥5%，直道实测≥4m/s距离占比单列。安全/可靠性回退即拒收，不能以更快失败抵消。

## 可视化与停止条件

视频同步显示原始识别、实际观测/历史支持/未知、参考点与选中轨迹、候选净空、实际速度和终止原因。显示训练开关当前是否通过准入以及哪项失败。

若依赖错误、传感器合同违例、模拟器物理变化或连续三次同类故障，停止该批试验并记录原因；修复后另开版本。训练启动后先验证有实际episode与GPU工作且无报错，即可退出持续监督，保留进度文件和停止入口。

## 2026-11-08 实验补充（不改变上述准入门槛）

- V3.3.3 起使用用户已说明的“两车道”类别先验；米制车道宽从本次相机白色涂装间距估计。它只收缩当前观测到的灰色路面，没有预载米制赛道地图。这个先验仍可能误判内侧可行驶区域，不应把它说成学会了任意道路拓扑；目前方案未获准入。
- V3.4.0 起比较包含停车的局部候选轨迹；V3.4.1 将路面与每个障碍的不确定度分别扣除。V3.4.2 的开发配置把不确定度系数从1.8改为1.0，几何余量0.18m不变，新鲜障碍在最长5s预测时的合计余量约0.45m。这是显式风险参数比较，不是通过概率标定，也不是训练所得。
- V3.4.3 让灰色路面上的亮白涂装、黑色裂纹共用色度判断；V3.4.4 仅在检测框两边都有路面像素时补充路面连续性，障碍物占用约束仍保留。这是推断，不声称看见遮挡后方。
- V3.4.5 修正候选终点切线与终点位置相冲突的问题，A/B/C 开发布局均通过，但连续障碍出界、两个空场整圈停滞，整版拒收。
- 初版开发批次没有自动执行“三次同类终止停止”的规则，V3.4.3 连续三次停滞后仍执行了后两段。结果全部保留并注明该流程缺陷，现已在 v34_trials.py 中加入自动停止；没有把这些开发结果当作预注册留出验收。
- 当前没有新增长训练；不能把未运行的4圈扰动/16段留出障碍、旧V3.2参数复用或新执行标定写成已通过。旧固定模型的短步拟合不证明5s预测可靠。
