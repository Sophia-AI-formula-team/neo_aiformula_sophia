Trial18 schema2: independent motion plus captured mask replay

This is an offline diagnostic, not a completed lap or runtime transport test.
The fixture contains 410 chronological image motion bindings, 4505 raw model
wheel/gyro samples and 107 exact 640x360 binary-mask PNGs for mapping images
304 through410. Warmup motion is retained. PNGs have only IHDR/IDAT/IEND chunks;
all channels are identical and contain only0/255. No RGB scene, human image,
raw world pose, course, GNSS observation or controller command is included.

Original per-sample QPC receipt, arrival, consumption and commit fields are
evidence, not synthetic replacement clocks. Replayed odometry must match the
stored digests. Image capture binds an exact acknowledged motion tail; latest
or future motion cannot substitute. Mapping stops at its first rejection.

Dependency packaging
  replay_observed_keyframe.py.txt imports motion_channel. Both source files are
  byte-for-byte copies with .txt suffixes for the evidence whitelist. Restore
  ordinary .py names only in a NEW local tools directory; do not edit evidence.
  Use an existing Python environment with NumPy and Pillow, plus Git. Do not
  install dependencies, start Unity, ROS, a server or vehicle control for replay.
  Importing motion_channel defines functions/classes only. Replay uses its pure
  protocol/timestamp helpers; it never creates the live Windows clock reader.

Interpretation and reproducibility limits
  All replay masks and priors belong to this captured development trajectory.
  A changed controller's new trajectory is not being replayed. This is not an
  independent held-out dataset or proof of new-lap geometry/localization quality.
  HTTP image arrival and every MMF/commit-guard read instant were not logged.
  No continuous watchdog,200ms admission scheduler, generation-lock interleaving
  or runtime stopping behavior can be inferred from these offline passes.
  Recorded HTTP-write completion is not Unity acknowledgement or actuation.
  The earlier replay01 report predates explicit timing-limit output fields;
  preserve it as historical evidence, not a claim of identical tool provenance.
  The profiler summary omits raw paths and most entries. It is not a standalone
  reproduction of the original profiling run. All raw diagnostic inputs remain
  local, are not package payloads and have not been approved for public upload.
  components_batch_01.json is a retained21-case microbenchmark/equivalence
  report, not a new live run. Its prototype source is not included and its
  own captured path ended with a matcher timeout. Do not call it runtime pass.
