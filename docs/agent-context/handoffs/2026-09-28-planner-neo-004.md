## 不可误解的边界

1. LYA 的参数是参考，实际反馈命令不恒为该数值；当前参考 2、前方误差 1 m 的简单测试为 2.15。
2. 默认 `accepted_teacher_max_speed_mps=0` 只表示**私有预览未配置**。非私有输出必须有
   三个原部署确认和明确审核过的正数教师上限。超过上限拒绝，不裁成假装相同的命令。
3. `_gnss` 现存 raw-motion 速度门限为 3；参考 4 仍继承为 4，但启动即拒绝其与门限的冲突。
   不自动提高门限，不等开车之后丢失运动链。更高速度需要测量和独立审核。
4. `0.35` 是 `v_ref²*|曲率|` 准入，不是反馈后每条 `v*omega` 的物理硬上限。
   合成测试峰值约 0.40244；不能据此声明已验证实际横向加速度安全。
5. motor 原有零命令旁路存在，但 STATE_BKUP 可绕过 max_command_v；4.0 不是已证明的统一限速。
   标准 allnodes 的 teleop 与命令出口可能冲突；必须先解决/验证单一命令所有权与停车链。
6. 原两个包仍用 VectorNav 融合链；`_gnss` 才是 CAN + raw gyro + mask、GNSS 仅两次停稳起点许可。
   不用 GNSS 建图，不用未来数据，不恢复 3 m 裁剪。`_gnss` 仍仅同一连续进程 teach→repeat。
