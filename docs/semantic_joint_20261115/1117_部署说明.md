## 复现实验前

确认 Unity 场景、编辑器所有权及全部源/资产哈希；保留其他修改。仿真器路径和MCP桥分别是：

```text

E:/Mess/School/SOPHIA/Y4T1/Research/Demo_LaneLineTrainer/workspace/tools/invoke_unity_bridge.py
```

只通过 Unity MCP 操作，不使用 Computer Use。先在 Edit 状态记录设置；本次临时设渲染30fps/vSync0，试跑后恢复-1/vSync1，timeScale1及fixedDeltaTime0.02。原始相机、物理、官方图和模型不改。

从仓库根目录，指定**独立、空的输出目录**，启动已连接正确编辑器的runner：

```powershell
$repo = (Get-Location).Path
$trial = 'E:/Mess/Projects/Programming/aiformula/workspace/semantic_1117_trial_20261117'
$sim = 'E:/Mess/School/SOPHIA/Y4T1/Research/Demo_LaneLineTrainer/Simulator'
$bridge = 'E:/Mess/School/SOPHIA/Y4T1/Research/Demo_LaneLineTrainer/workspace/tools/invoke_unity_bridge.py'
$source = Join-Path $repo 'workspace/src/aiformula/perception/semantic_planning_system'
$archive = Join-Path $repo 'codexws/unity_semantic_joint_20261116'
python (Join-Path $archive 'trials/run_joint_trial.py') inner_NEW --lane inner --output-root (Join-Path $trial 'runs') --source-root $source --worker-root (Join-Path $archive 'transport') --simulator $sim --bridge-script $bridge --expected-harness-sha256 800e531be28c94a6afed0c61d5b94dbd8718d8703ec55231c0cc24f9a5525ff6 --expected-transport-sha256 cf506d82e22f1cf10ea26011229bad71c3e368a97121d9673039bb25ea0911a8 --wall-timeout 900
```

外圈改 `--lane outer` 和新名称。现有runner只认这两个 reviewed Unity资产哈希，会对源与固定依赖运行前后哈希；不可覆盖已有run。内圈默认 `component-only`，外圈 `baseline`。运行中记录的 `ready.json`、帧、事件、semantic ticks、控制状态与 `result.json` 都保留。人工停止后 `result.accepted=false` 是旧的两圈绕行验收结果，**要另看 `terminalStatus.status.map_fusion` 和节点**。

本接线假设避障与外部分支均未占用，且没有实时接入这两个topic；详见[输入逐项审计](1117_接线审计.md)。RGB灯牌模式是Unity特定接线，非实车检测升级。实跑的自动红灯两场均因 `red_wait_near_junction` 没有绕行。
