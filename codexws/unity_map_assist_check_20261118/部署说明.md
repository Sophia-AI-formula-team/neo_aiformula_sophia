# MapAssist 0.4.4 仿真接线

从 `map_assist_check.zip` 导入两个 ROS 包，保留供应方实现和配置，版本统一为 0.4.4。上游说明与既有验证结论见同目录。官方拓扑仍由原包加载。

Unity MCP 使用 MotorControllerValidation 场景和既有 LYA。将上游仿真适配器作为独立 worker，应用 `unity_flag_stop.patch` 后，仅在 worker 握手声明 `rgb_panel_range_8p5m` 时启用新输入。每次实际相机新帧使用已有 RGB 灯牌框中心和相机标定得到车头纵向距离，距离有效且不超过 8.5 m 时发送 True。有效且大于阈值时发送 False。无效或过期时不更新距离标志，上游节点保留最后一次值，未实现距离话题超时。距离观测与发布值随 semantic 输出记录。

本次使用供包默认的 UBS 半径 4.0 m、前瞻 1.5 m 和裁剪 12.0 m。保持原 LYA、相机、灯位和车辆物理。进程内消息适配使用 Unity 刚体里程计。当前仿真沿用避障空闲与分支默认状态，动态释放及连续不同灯事件未纳入本次测试。只运行内外圈各一次，以及闭环、UBS 和交通状态的相关单元测试。

启用时应使用独立 worker 目录，将 `semantic_joint_worker.py` 放在其中，并向既有试跑 runner 指定新包根目录与 worker 路径。原接线可用恢复原 C# 文件并经 Unity MCP 导入的方式回退。请勿将仿真距离接线用于实车。
