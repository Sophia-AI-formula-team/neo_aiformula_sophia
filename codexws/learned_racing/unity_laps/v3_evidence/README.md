# V3 驾驶实验与 GPU 长训练

日期：2026-11-07。输入基线 `f5d9a12`。本轮为开发实验，未部署实车。

## 版本与学习内容

|版本|实现|状态|
|---|---|---|
|V3.0|显式有限时域车辆运动预测、车身碰撞检查、局部道路和速度候选|开发基线|
|V3.1|同一规划器，CEM 通过试错学习速度、响应、转向平滑、风险余量等 9 个参数|36 次开发试跑及后续 CPU 对照|
|V3.2|同一参数学习，CUDA Graph 并行预测 256 个环境、每环境 60 个候选|30,000 次后台训练已启动；未完成验收|

这不是端到端神经驾驶网络。学到的参数、动力学拟合、约束和每次决策都能检查。轨迹搜索没有要求回到内侧或外侧车道。有限时域效率仍不能替代严格的全局最优圈速证明。

CUDA 执行批量轨迹预测；程序化车辆物理、传感器生成和小规模 CEM 参数更新在 CPU。机器只有一张 RTX 4070 Ti。960 次演化传感器输入对照中，CPU/GPU 最大指令差异为 3.33e-7；32 环境规划部分计时约 0.0954 s 对 0.4396 s（20 次，CPU 单进程）。这不是端到端加速比。此前 128 次 CPU 四进程约 7.7 s；GPU 初版约 25 s，CUDA Graph 版约 13 s。最终 256 环境开发批约 17.2 s，但各批的源代码/采样方案不同，不作为严格速度消融。

## 数据边界审计

旧版 `OuterEdgeSections` 用固定 `HALF_LANE` / `3*HALF_LANE` 将可见边界平移为外侧车道参考，还会在边界观测范围之外外推。旧版 `ObjectTracker.Update` 接收 Unity 真实位置和朝向，构成不应进入新控制侧的理想自运动信息。无相机模式的 `Track.LocalLane` 也是几何真值传感器，不是 YOLOP。

V3 的 Unity 分支绕过旧 `Policy.Act`、真实位姿跟踪器和 `LocalLane`。发送到 Python 的字段严格限于 RGB、时间、轮速代理 RPM、固定轮径和 raw gyro。Python 验证字段白名单；没有位置、朝向、圈进度、赛道地图或未来路障数据。真实地图只在环境、裁判和观看画面中使用。道路区域由当前 A4 白线及 RGB 路面颜色提取，保留可见范围，缺观测时不补出外圈参考。它仍会误识别；目前的颜色区域与弯道连接关系远未解决。

当前 Unity 接触模型的 RPM 字段是电机模型目标转速代理，不是独立编码器。gyro 为理想仿真原始角速度。不能把这些接口描述成已验证的真实传感器。

## 训练计划与计数

运行目录：`../.work/v3_2_long_30000_20261107/`。`owner.json` 保存 PID 和命令；`index.html` 为每轮更新的进度，`preview.html` 为检查点独立 CPU 评估回放，`attempts.jsonl` 保留每次试错，`checkpoints/` 保留各轮模型，`sources/` 保存运行时源码快照。

目标是 30,000 次真实执行的程序化闭环试次，绝不将内部候选轨迹数当作试次。32 个参数候选 × 8 个场景 = 每轮 256 个并行环境。每轮共享 2 个配对场景，每个候选另有 6 个独立生成的场景，预计超过 20,000 个独立场景种子。第一圈不加载完整地图。A/B/C 分别包含可钻缝、中间不足需绕行、两者均可选择；另有连续、移动、混合、弯中、空场及观测缺失。窄缝中心显式列入候选，避免粗采样漏掉通路。

评分先比较完成/失败，再比较按赛道长度归一化的整圈时间；短时间撞车不能获得快圈奖励。风险是几何净空扣除不确定性，尚不是经过标定的碰撞概率。失败全部保留。检查点不是获准替换基线的模型；独立 Unity 验证仍须另做。

代理动力学使用既有 45 段 Unity 训练轨迹拟合，另 15 段做单步检查；详见 `plant_fit.json`。速度和 yaw 的单步误差不证明多步预测精度，也不证明实车换电适应。GPU 长训练不是 30,000 次 Unity/PhysX 运行。

## 操作与停止

创建运行目录内的 `STOP` 文件会在当前批次结束后停止。恢复用原参数加 `--resume`；源码摘要不同会拒绝恢复，避免悄悄混合版本。未清除 STOP 前恢复仍会停止。运行正常完成首轮更新后，按用户要求退出持续监督；没有创建自动监控任务。
