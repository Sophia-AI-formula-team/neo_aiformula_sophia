# 仿真接线与首圈复现

使用两个 0.4.5 ROS 包及本目录的进程内 worker。先在独立 Simulator 会话应用 unity_flag_stop.patch 和 unity_one_lap.patch。沿用原有 LYA、相机、灯位与车辆物理参数。由相机灯牌纵向估距产生 flag_stop，阈值 8.5 米，有效新帧才更新。避障与分支继续使用仿真默认状态，不能据此评价动态避障。

通过 Unity MCP 然后使用上次的试验 runner，以 inner 车道指定新版本 semantic 包根目录及本目录 worker。第一圈红灯停车后，试验程序切绿，闭环并接受拓扑后停止。对照上次 runner 所需的程序哈希替换为应用 patch 后的哈希。跑完还原原 C# 文件并通过 MCP 导入。报告及有限验证范围见结果.md。
