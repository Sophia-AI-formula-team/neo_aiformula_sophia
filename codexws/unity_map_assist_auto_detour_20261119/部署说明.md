# MapAssist Auto 0.4.5 红灯绕行仿真

本目录依赖 PR #42 的 Semantic 0.4.5 源码，基线为 `1f099e2ddaf18ebde1cdfcac80f7d6f948719338`。归档用途为现有 Unity Simulator 的内圈绕行试跑，可使用 `profiles/` 中任一参数组复现。本目录继承 `codexws/COLCON_IGNORE`。

## 从右下角复现

1. 在专用 Simulator 会话确认 Unity MCP 已连接，编辑器处于干净的 Edit 模式，场景为 `MotorControllerValidation`。备份 patch 中的两个 C# 文件及其 SHA-256。原始文件 SHA-256 分别为 `baa608195c491d369ac91439a14c0e0185d5f79e0a866a8a89b7e8e1f08b7f00` 和 `cf506d82e22f1cf10ea26011229bad71c3e368a97121d9673039bb25ea0911a8`。
2. 将这两份 C# 文件复制到空的暂存目录，保持相对路径，统一为 LF。对暂存目录执行 `git apply --check` 和 `git apply` 加上本目录 `unity_warm_detour.patch` 的绝对路径。将两份输出转回 CRLF 后核对 SHA-256，再放回对应路径，通过 Unity MCP 导入，等待编译完成并读取 Console 错误。
3. 创建本次运行独立的 worker 目录，放入本目录 `semantic_joint_worker.py`、`accepted_map_snapshot.json`。复制所选 profile，命名为 `trial_parameters.json`。`detour_03` 对应内侧转向饱和，`detour_07` 是这批试跑中绕行参考进度最远的一组。
4. 用下列参数运行本目录的 `run_detour.py`。`BRIDGE_SCRIPT` 指向 Simulator 上一级项目的 `workspace/tools/invoke_unity_bridge.py`，端口按 MCP 实际监听设置。启动前确保原 Simulator 已能运行已安装的 LYA 与识别 worker。

```text
python run_detour.py CASE --lane inner --output-root RUNS --source-root SEMANTIC_PACKAGE_ROOT
  --worker-root WORKER_DIR --simulator SIMULATOR_ROOT --bridge-script BRIDGE_SCRIPT --port 6400
  --expected-harness-sha256 f46ecd9ae868ca23f4451a2bff811b20d3942d08a98051c14f836c46456c99c7
  --expected-transport-sha256 34e03fbef168c1515ca61da4710c44d4993f168dfffa785823960792b530347f
  --wall-timeout 125
```

地图快照严格校验源码字节。Windows Git 的换行转换可能使同一个 commit 的文件哈希不同。复现时可将 0.4.5 包复制到试验目录，按已测基线将以下三份文件保存为 LF，其余文件保留原有字节。源码树校验值为 6aa6bdc1d2c4171d829fb25010eb50931f559e0018e8a3f98e39ebbc40ca4bd5。

- semantic_local_planner_ros/tests/test_auto_turn.py
- semantic_local_planner_ros/tests/test_ubs_map_assist.py
- semantic_planner_core/setup.py

5. 查看 `result.json` 和控制记录。通过条件包括真实红灯识别后左转、回到主路，并在正常模式继续至少 5 米。退出码 2 表示未通过或输入文件在运行中发生变化。结束后将两份原始 C# 恢复并核对哈希，再由 MCP 导入并确认返回干净 Edit 状态。

## 输入与结果

- `accepted_map_snapshot.json` 来自首圈实跑，包含通过匹配的模拟地图。worker 校验源码树哈希、参考线长度与拓扑节点；运行时读取相机识别和 Rigidbody 里程计。
- RGB 灯牌估距仅生成既有 8.5 米 `flag_stop`。车辆实际经过触发范围时切红灯，场景灯状态用于试验编排和记录。Semantic 与 LYA 源码、车辆物理和保护门限沿用原值。OA/branch 沿用仿真默认状态。
- `summary.json` 记录七次试跑和饱和实测点。七次均实际左转入内，尚未完成回主路。`detour_03` 在仿真 25.406 秒的 LYA 与施加角速度指令均为 −2.00 rad/s，实测 −0.098 rad/s，后来触发横向偏差或航向超限。`detour_07` 的绕行参考进度为 41.06 米。
- 大体积运行日志和视频保留在本地。此次验收环境为 Unity 和进程内 ROS 接线。
